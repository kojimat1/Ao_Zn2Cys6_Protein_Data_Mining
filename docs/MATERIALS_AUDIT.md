# Materials audit

## Included and directly usable

- Analysis notebooks and the supporting non-DBD FASTA finalization script
- SM00066 protein ID lists
- The merged InterProScan result used for SM00066-based protein selection
- aaComp descriptor tables and the protein/DBD length table
- Curated ortholog lists for the six related species
- Curated AO090005001236/BGC and ortholog workbooks used for synteny visualization
- Workflow documentation and validation reports

## Required but not redistributed

The following source or intermediate files are required to rerun some workflows but are not redistributed because an explicit redistribution license could not be confirmed:

- CAoGD/CAoGDX-derived genome and protein sequences
- GTF annotations for the seven species
- Full-length, DBD, and non-DBD FASTA datasets
- antiSMASH JSON files containing genome sequences and annotations
- Newick trees and iTOL annotation files generated by the phylogenetic notebook

The Newick trees and iTOL annotation files can be regenerated by running the phylogenetic-analysis notebook after obtaining the required sequence inputs.

## Source-preparation input validation

- The SM00066 list contains 233 unique IDs.
- `aor0-5.faa` and `aor0-5_2.faa` each contain 11,902 unique protein records.
- Every one of the 233 SM00066 IDs occurs in both FASTA files.
- `aor0-5_merged.tsv` contains 113,601 rows, including 234 rows annotated with SM00066.
- The CaoGD mapping table contains 11,902 rows.
- The sequence workbook contains 234 data rows and the expected gene ID, description, chromosome, protein-sequence, and DBD-sequence fields.

The 234 SM00066 annotation rows are compatible with 233 unique proteins because one protein can contribute more than one DBD annotation.

The sequence-preparation notebook completed successfully with these inputs. Its general non-DBD rule generated 232 sequences because AO090012000182 has a C-terminal DBD and is excluded by that rule. The added helper script `scripts/finalize_non_dbd_fasta.py` applies the documented exception, extracts residues 1-581, and reproduces the fixed 233-sequence fixed non-DBD FASTA used in the study.

## Generated workflow dependency

`260923_AO_TF_PCA.ipynb` reads:

- `Domain_itol_colorstrip_support_k10.txt`
- `FL_itol_colorstrip_support_k10.txt`
- `non_DBD_itol_colorstrip_support_k10.txt`

These are generated by `260922_AoTF_Phylogenetic_Tree_Analysis.ipynb`. Run the phylogenetic notebook first and upload the three generated files together with the aaComp CSV files. They are intermediate outputs and are not missing primary input data.

## Files retained although not directly read by the supplied notebooks

The six related-species antiSMASH JSON files are required by the species-specific BGC-proximity notebooks but are not redistributed in this repository. They are not directly read by the final synteny notebook, which uses the deposited curated XLSX workbooks together with the corresponding species-specific GTF files. The GTF files are also not redistributed.

## Scope of reproducibility

The repository contains the analysis notebooks, scripts, selected redistributable inputs, and derived data underlying the revised computational analyses. Some workflows cannot be rerun directly from the repository alone because CAoGD/CAoGDX-derived sequences, annotations, derived FASTA datasets, and antiSMASH JSON files are not redistributed. Their provenance and required basenames are documented so that authorized users can obtain or regenerate them from the original sources.
