# Reproducible analyses of *Aspergillus oryzae* GAL4-like Zn2Cys6 proteins

This repository contains the Google Colab notebooks, scripts, selected redistributable analysis inputs, derived data, and workflow documentation used for the revised analyses of GAL4-like Zn2Cys6 proteins in *Aspergillus oryzae* RIB40 and related *Aspergillus* species. Source genome sequences, protein sequences, gene annotations, and antiSMASH JSON files are not redistributed and should be obtained or regenerated from the original sources as described below.

## Repository layout

```text
notebooks/                         Analysis notebooks
scripts/                           Supporting analysis scripts
input_data/bgc_proximity/          Redistributable TF-ID input
input_data/ortholog_lists/         Curated ortholog lists for six related species
input_data/pca/                    Amino-acid-composition and length tables
input_data/source_preparation/     Redistributable InterProScan results and ID list
input_data/synteny/                Curated BGC and ortholog workbooks
docs/                              File inventory and validation reports
```

Notebook outputs are intentionally excluded. Each notebook creates its own results or download archive.

## Recommended workflow

The notebooks were developed for Google Colab. Open a notebook in Colab and upload the files listed below to `/content` without changing their basenames.

| Order | Notebook or script | Required inputs |
|---:|---|---|
| 1 | `SM00066_domain_and_non_DBD_sequence_extraction.ipynb` | Source files listed in `input_data/README.md`; some CAoGDX-derived source files are not redistributed |
| 1b | `scripts/finalize_non_dbd_fasta.py` | Raw non-DBD FASTA generated in step 1, the complete protein FASTA, and the SM00066 result table |
| 2 | `260904_AoTF_DBD_Length_histogram_revised.ipynb` | `input_data/pca/aor0-5_SM00066_Protein_ID_Length.csv` |
| 3 | `260922_antiSMASH_area_based_bgc_proximity_sensitivity.ipynb` | The *A. oryzae* antiSMASH JSON and GTF files, which are not redistributed, and `input_data/bgc_proximity/SM00066_ID_list.txt` |
| 3b | `260721_antiSMASH_area_based_with_reference_set_*.ipynb` | The corresponding species GTF and antiSMASH JSON files, which are not redistributed, and the curated ortholog list in `input_data/ortholog_lists/` |
| 4 | `261012_AO090005001236_synteny.ipynb` | The two workbooks in `input_data/synteny/` and the seven species GTF files, which are not redistributed |
| 5 | `260727_STREME.ipynb` | DBD, non-DBD, and full-length FASTA files, which are not redistributed |
| 6 | `260922_AoTF_Phylogenetic_Tree_Analysis.ipynb` | DBD, non-DBD, and full-length FASTA files, which are not redistributed |
| 6b | `260922_Mantel_test_pairwise_3_trees_Spearman_Holm.ipynb` | `Domain_tree.nwk`, `non_DBD_tree.nwk`, and `FL_tree.nwk` generated in step 6 |
| 7 | `260923_AO_TF_PCA.ipynb` | The three aaComp CSV files in `input_data/pca/` and the three iTOL color-strip files generated in step 6 |
| 8 | `260925_PCA_threshold_sensitivity_analysis.ipynb` | The three aaComp CSV files in `input_data/pca/` |
| 9 | `260925_PCA_sequence_length_effect_analysis.ipynb` | The three aaComp CSV files and the corresponding FASTA files; the FASTA files are not redistributed |

The six species-specific notebooks represented by step 3b evaluate whether orthologs of the 48 *A. oryzae* genes classified as BGC-associated at the primary 20-kb threshold are also located near antiSMASH-predicted BGCs in the related species. The deposited curated ortholog lists are located in `input_data/ortholog_lists/`. The corresponding GTF annotations and antiSMASH JSON files are required to run these notebooks but are not redistributed.

The ortholog lists were manually compiled from CAoGD and are therefore provided as curated input data rather than as notebook-generated outputs.

The Mantel-test notebook in step 6b compares patristic-distance matrices derived from the DBD, non-DBD, and full-length phylogenetic trees. Spearman correlations are used as the primary statistics, and pairwise P-values are adjusted using the Holm method.

The Newick trees used by the Mantel-test notebook are generated by the phylogenetic-analysis notebook and are not currently deposited as separate reference-output files.

The sequence-preparation notebook applies its general C-terminal extraction rule and therefore omits AO090012000182, whose DBD is near the C terminus. Run `scripts/finalize_non_dbd_fasta.py` after the notebook to reproduce the fixed non-DBD FASTA exactly.

## Software

Python dependencies are listed in `requirements.txt`. The phylogenetic workflow additionally installs MAFFT and FastTree. The motif workflow creates a Conda environment containing MEME Suite 5.5.9 and runs STREME. Google Colab is recommended because several notebooks use `google.colab.files` and `/content` paths.

## Restricted source data

Genome sequences, protein sequences, gene annotations, and antiSMASH JSON
files derived from CAoGD/CAoGDX are not redistributed in this repository
because an explicit redistribution license could not be confirmed.

The antiSMASH JSON files are also excluded because they contain copies of
the input genome sequences and annotations. Users should obtain the source
data directly from CAoGD/CAoGDX and regenerate the antiSMASH results using
the versions and settings described in the manuscript.

Required filenames and workflow dependencies are documented in
`input_data/README.md`.

CAoGDX: https://nribf21.nrib.go.jp/CAoGDX/
