# Input data

Files are grouped by analysis to make the provenance and upload requirements clear. The notebooks retain their original Google Colab behavior and generally expect required files to be uploaded to `/content` with the same basenames shown here.

- `annotations/`: GTF annotations for *A. oryzae*, *A. flavus*, *A. clavatus*, *A. nidulans*, *A. fumigatus*, *A. niger*, and *A. terreus*.
- `sequences/`: DBD, non-DBD, and full-length protein FASTA files.
- `pca/`: aaComp descriptor tables and the protein/DBD length table.
- `bgc_proximity/`: the *A. oryzae* antiSMASH JSON file and SM00066 ID list.
- `ortholog_lists/`: curated ortholog lists for the 48 *A. oryzae* genes classified as BGC-associated at the primary 20-kb threshold.
- `synteny/`: curated AO090005001236/BGC and ortholog workbooks.
- `antismash_related_species/`: supporting antiSMASH JSON files for the six related species.
- `source_preparation/`: merged InterProScan results, complete-proteome FASTA files, the CAoGD mapping table, the 233-ID list, and the protein/DBD sequence workbook used by the sequence-extraction notebook. `aor0-5_merged.tsv` is the merged InterProScan result used to identify
proteins containing the SM00066 domain. It contains protein identifiers,
sequence checksums and lengths, domain matches, coordinates, scores, and
functional annotations, but does not contain the underlying amino acid
sequences. The source protein FASTA files are not redistributed.

See `../docs/MATERIALS_AUDIT.md` for workflow dependencies and scope limitations.

## Ortholog lists

The `ortholog_lists/` directory contains ortholog lists compiled for the
48 *A. oryzae* GAL4-like Zn2Cys6 genes classified as BGC-associated at the
primary 20-kb threshold. Orthologs in six related *Aspergillus* species were
identified using CAoGD and were subsequently evaluated for proximity to
antiSMASH-predicted BGCs using the corresponding species-specific notebooks.

Because the ortholog assignments were manually compiled from CAoGD, these
files are treated as curated input data rather than outputs generated by
the notebooks. The extensionless filenames are retained because the
species-specific notebooks refer to these exact basenames.

## Restricted source files

The following source files are required by the deposited notebooks but are
not redistributed in this repository:

- GTF annotations for the seven species
- CAoGD/CAoGDX-derived genome and protein sequence files
- Full-length, DBD, and non-DBD FASTA datasets derived from those sequences
- antiSMASH JSON files containing the input genome sequences and annotations

Users should obtain the corresponding source data from CAoGD/CAoGDX and
retain the basenames documented in the notebooks. The antiSMASH JSON files
should be regenerated by submitting the corresponding genome FASTA and GFF3
files to fungal antiSMASH under the conditions described in the manuscript.
