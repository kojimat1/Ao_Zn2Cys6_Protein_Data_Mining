# Input data

This directory contains selected deposited analysis inputs and derived data used by the notebooks in this repository. The notebooks were developed for Google Colab and generally expect the required files to be uploaded to `/content` without changing their basenames.

Some source and intermediate files required by the notebooks are not redistributed because an explicit redistribution license for the underlying CAoGD/CAoGDX data could not be confirmed. Their provenance and required file types are described below.

## Deposited directories

### `bgc_proximity/`

Contains the SM00066-positive protein ID list used in the *Aspergillus oryzae* BGC-proximity analysis:

- `SM00066_ID_list.txt`

The corresponding *A. oryzae* GTF annotation and antiSMASH JSON file are required by the BGC-proximity notebook but are not redistributed.

### `ortholog_lists/`

Contains manually compiled candidate-ortholog lists for the 48 *A. oryzae* genes classified as BGC-associated at the primary 20-kb threshold:

- `acl0-1_48_gene_ortholog`
- `afl0-1_48_gene_ortholog`
- `afu0-1_48_gene_ortholog`
- `and0-2_48_gene_ortholog`
- `ang0-2_48_gene_ortholog`
- `atr0-1_48_gene_ortholog`

The candidate orthologs were manually compiled from CAoGD and were subsequently evaluated for proximity to antiSMASH-predicted BGCs using the corresponding species-specific notebooks.

These files are treated as curated input data rather than as notebook-generated outputs. Their extensionless filenames are retained because the species-specific notebooks refer to these exact basenames.

The corresponding species-specific GTF annotations and antiSMASH JSON files are required to run these notebooks but are not redistributed.

### `pca/`

Contains amino-acid-composition descriptor tables and the protein/DBD length table used in the PCA and sequence-length analyses:

- `aaComp_MolePct.csv`
- `non_DBD_aaComp_MolePct.csv`
- `FL_aaComp_MolePct.csv`
- `aor0-5_SM00066_Protein_ID_Length.csv`

The three aaComp tables correspond to the DBD, operationally defined non-DBD, and full-length sequence datasets, respectively.

### `source_preparation/`

Contains the deposited inputs used to identify the SM00066-positive protein set and document the InterProScan-based selection:

- `aor0-5_merged.tsv`
- `aor0-5_SM00066_ID_list.txt`

`aor0-5_merged.tsv` is the merged InterProScan result used to identify proteins containing the SM00066 domain. It contains protein identifiers, sequence checksums and lengths, domain matches, coordinates, scores, and functional annotations, but does not contain the underlying amino acid sequences.

The complete-proteome FASTA files, CAoGD/CAoGDX sequence-mapping table, and protein-sequence workbook used during sequence preparation are not redistributed.

### `synteny/`

Contains the curated workbooks used for the comparative genomic-context and synteny analysis of AO090005001236 and neighboring predicted β-lactone BGCs:

- `AO090005001236_antiSMASH_20kb.xlsx`
- `AO090005001236_betalactone_BGC_ortholog.xlsx`

The corresponding GTF annotations for *A. oryzae* and the six related *Aspergillus* species are required by the synteny notebook but are not redistributed.

## Required but not redistributed

The following source or intermediate files are required to rerun one or more deposited notebooks but are not included in this repository:

- GTF annotations for *A. oryzae*, *A. flavus*, *A. clavatus*, *A. nidulans*, *A. fumigatus*, *A. niger*, and *A. terreus*
- CAoGD/CAoGDX-derived genome and protein sequence files
- The complete-proteome FASTA files used for sequence preparation
- The DBD, operationally defined non-DBD, and full-length FASTA datasets derived from the source protein sequences
- The *A. oryzae* antiSMASH JSON file used for the BGC-proximity analysis
- The six related-species antiSMASH JSON files used for the ortholog BGC-proximity analyses

Users should obtain the corresponding genome, protein, and annotation data directly from CAoGD/CAoGDX and retain the basenames expected by the notebooks.

CAoGDX is available at:

https://nribf21.nrib.go.jp/CAoGDX

The antiSMASH JSON files should be regenerated by submitting the corresponding genome FASTA and GFF3 files to the fungal antiSMASH web server using the version and settings described in the manuscript. These JSON files are not redistributed because they contain copies of the input genome sequences and annotations.

## Generated intermediate files

The following files are generated during the documented workflow and are not deposited as separate reference outputs:

- `Domain_tree.nwk`
- `non_DBD_tree.nwk`
- `FL_tree.nwk`
- iTOL tree-color and color-strip annotation files generated by the phylogenetic-analysis notebook
- DBD, non-DBD, and full-length FASTA files generated during sequence preparation
- Notebook-specific result tables, figures, and download archives

Run the notebooks in the order described in the root `README.md`. In particular, run the phylogenetic-analysis notebook before the Mantel-test and main PCA notebooks because those analyses use Newick trees or iTOL annotation files generated by the phylogenetic workflow.
