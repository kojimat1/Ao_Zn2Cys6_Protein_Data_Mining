## BGC proximity analysis of orthologs in related *Aspergillus* species

The six species-specific notebooks determine whether orthologs of the 48
*A. oryzae* GAL4-like Zn2Cys6 genes classified as BGC-associated at the
primary 20-kb threshold are also located near antiSMASH-predicted BGCs in
six related *Aspergillus* species.

The notebooks use the species-specific GTF annotations in
`../input_data/annotations/`, antiSMASH JSON files in
`../input_data/antismash_related_species/`, and manually compiled ortholog
lists in `../input_data/ortholog_lists/`.

The ortholog lists were manually compiled from CAoGD and are provided as
curated input data rather than as notebook-generated outputs.

## Mantel tests

`260922_Mantel_test_pairwise_3_trees_Spearman_Holm.ipynb` performs pairwise
Mantel tests among the phylogenetic distance matrices obtained from the DBD,
operationally defined non-DBD, and full-length sequence trees. Spearman
correlations are used, and the resulting P values are adjusted using the
Holm method.

The notebook can use the Newick trees generated by
`260922_AoTF_Phylogenetic_Tree_Analysis.ipynb` or the reference trees
provided in `../reference_outputs/phylogenetic_trees/`.
